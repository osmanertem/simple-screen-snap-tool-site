# Simple Screen Snap Tool — Support & Privacy site

Static support and privacy-policy pages for the Mac App Store app **Simple Screen Snap Tool**, hosted on GitHub Pages.

Plain HTML and CSS: no build step, no JavaScript, no analytics, no cookies, no external fonts.

| Page | English | Türkçe |
| --- | --- | --- |
| Support | `index.html` | `tr/index.html` |
| Privacy Policy | `privacy.html` | `tr/privacy.html` |

Shared styles live in `style.css` (light and dark via `prefers-color-scheme`). `.nojekyll` tells GitHub Pages to serve the files as-is.

## URLs for App Store Connect

- Support URL: `https://osmanertem.github.io/simple-screen-snap-tool-site/`
- Privacy Policy URL: `https://osmanertem.github.io/simple-screen-snap-tool-site/privacy.html`

## Editing

Open any `.html` file directly in a browser to preview. When you change the support email or privacy policy, update both languages and, for the policy, the effective date.

## Publishing

GitHub Pages serves the `main` branch from the repository root. Pushing to `main` updates the live site within a minute or two.
